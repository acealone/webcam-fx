# Clones effect + crossed-fingers gesture + 16:9

Date: 2026-11-25 · Status: approved by the user in chat

## Intent
Second gesture/effect pair for webcam-fx. Crossing index+middle fingers of both hands like a plus sign
(one hand vertical, one horizontal — not an X) makes smoke burst left and right of the user, two
doppelgangers appear in the smoke, stay a few seconds and vanish in smoke again. Picture becomes 16:9.

## Decisions (user)
- Clones are **live mirrors**: they move exactly like the user (no delay, no snapshot).
- 16:9 output.

## Approach (one sensible way each)
- Gesture: geometry on the existing mediapipe hand landmarks (no new model).
- 16:9: webcam's native 640x360 mode — measured 29.8 fps (800x448/864x480 ~20 fps, 960x544 ~15 fps).
  Cropping 640x480 was the fallback; not needed.
- Smoke + sound: procedural/generated, original. No anime assets.

## Design
- `gestures/crossed_fingers_plus/`: both hands two-finger pose (index+middle stretched, ring+pinky folded);
  finger direction of one hand within 30° of vertical, the other within 30° of horizontal, measured in
  pixels (aspect-corrected); the two finger segments must intersect. `needs = {"hands"}`.
- `effects/clones/`: timeline smoke-in (0.6 s, clones fade in inside the smoke) → shown (4 s) → smoke-out
  (0.6 s, clones fade out) → done. Clones = user cut-out scaled 0.85, bottom-aligned, centred at
  ±0.32·width; drawn behind the user (bg → clones → smoke → user). "poof" sound at both smoke bursts,
  generated by `make_sounds.py`. Settings `duration`, `scale`, `offset`, `smoke` in `[effects.clones]`.
- `config.toml`: camera 640x360; new trigger `crossed_fingers_plus → clones`.
- User presses `b` once (saved background has the old size and is ignored with a message).

## Non-goals
Independent clone movement, more than two clones, clone count/positions per gesture.
